# Student Result Analysis

## Project Overview

Student Result Analysis is a beginner-level data analysis project that explores student academic performance using Python. The project analyzes students' Math, Reading, and Writing scores along with demographic and educational factors.

The goal of this project is to understand patterns in student performance and demonstrate how Python can be used for data cleaning, exploratory data analysis, and visualization.

## Project Objective

- Analyze student academic performance.
- Clean and prepare the dataset for analysis.
- Compare Math, Reading, and Writing scores.
- Analyze the relationship between parental education and student performance.
- Explore weekly study hours and test preparation.
- Visualize student data using charts and graphs.
- Identify meaningful patterns and insights from the dataset.

## Dataset

The dataset contains student information such as:

- Gender
- Ethnic Group
- Parental Education
- Parental Marital Status
- Weekly Study Hours
- Test Preparation
- Math Score
- Reading Score
- Writing Score

The dataset was obtained from Kaggle.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Data Analysis Performed

The following analyses were performed:

- Dataset overview and descriptive statistics
- Missing-value analysis
- Data cleaning
- Gender distribution
- Ethnic group distribution
- Parental education analysis
- Parental marital status analysis
- Weekly study hours analysis
- Test preparation analysis
- Math, Reading, and Writing score analysis
- Score distribution using boxplots
- Heatmaps for comparing average scores
- Pie charts and countplots for categorical distributions

## Key Insights

- Student performance varies across different demographic and educational categories.
- Parental education can be compared with students' average academic scores.
- Weekly study hours provide useful information for analyzing student performance.
- Test preparation can be analyzed to understand differences in average student scores.
- The distributions of Math, Reading, and Writing scores show differences across students.

## Conclusion

This project demonstrates the use of Python for data cleaning, exploratory data analysis, and data visualization. It helped in understanding student performance and identifying patterns from educational data.

The project also strengthened my practical knowledge of Pandas, Matplotlib, Seaborn, and exploratory data analysis.
